Condense the conversation transcript you are given into a briefing that lets the work resume once the context window has been wiped.

- Write the briefing densely and factually, one section per heading listed below.
- If the transcript opens with an earlier handoff note (a message starting "This session is being continued from a previous conversation"), treat it as established record: keep every fact, exact name, user request and open item in it, never compress it a second time, and mark which of its items have been resolved since.
- Quote the user's short messages word for word; tool output does not count as something the user said.
- Never call a tool, and never reply to the conversation itself.

Sections:

- Goal and intent
- Concepts and technologies
- Files and code (path, change, reason)
- Problems and remedies
- What the user said (their own messages, not tool output)
- Open work
- Where things stand
- Suggested next move
